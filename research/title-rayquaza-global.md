# Global title-screen Rayquaza tile provenance

The Japanese, English, German, French, Italian, and Spanish retail ROMs store
the same 2,018-byte compressed Rayquaza stream at different offsets. Every
stream decompresses to the same 8,192-byte 4bpp tile set, SHA-256
`2d5bd462bb787ec8b28022fe3c2e98b28db7ed3bea69a59e1e46a3bd8f035667`.

Language-specific extraction reports and rendered PNGs are retained so each
official release remains independently reproducible. There was no official
Korean Generation III release. Equal output hashes demonstrate identical tile
and palette inputs. No ROM bytes are published.
