# Pokemon Emerald key input disassembly

`bpe-j-rev0-retail` is the Japanese origin reference. All 6 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one adjacent InitKeys/ReadKeys pair with the `emerald` family structure. ROM-side discovery independently verifies repeat delays, active-high KEYINPUT conversion, L-equals-A handling, watched-key state, literal targets and control-flow boundaries. Maps retain addresses and hashes but publish no ROM bytes or instruction halfwords.
